# CHANGELOG

All notable changes to this project will be documented in this file.

---

## v1.0.0

Initial Release

### Included Systems

#### Locomotion

* CharacterController-based movement
* Walk, Run, and Sprint support
* Jump support
* Free-look camera
* Camera collision handling
* Lock-on targeting
* Target switching

#### Combat

* Hitscan shooting
* Semi-auto fire mode
* Full-auto fire mode
* Shotgun support
* Reload system
* Weapon swapping
* Direct weapon slot selection
* HitBox-based damage system

#### Integration

* Unified locomotion and combat workflow
* Single-camera TPS setup
* Integrated aiming system
* Player rotation coordination
* Animator integration bridge
* CQB demo scene

### Demo Content

* Demo_Locomotion

### Requirements

* Unity 6 (6000.x)
* Built-In Render Pipeline
* New Input System
